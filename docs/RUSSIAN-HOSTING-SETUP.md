# «Наш остров» на российском сервере (работает без VPN)

Эта инструкция — как поднять **свой собственный Supabase** на российском хостинге
(Timeweb Cloud) и подключить к нему копию приложения. Тогда всё работает из России
без VPN, потому что и приложение, и сервер — в России.

> **Не спеши и не бойся.** Шагов много, но каждый простой. На любом шаге можешь
> прислать мне то, что видишь на экране (текст ошибки, вывод команды), и я подскажу,
> что дальше. Команды нужно вставлять по одной.

**Что уже сделано в коде (моя часть):**
- копия приложения лежит в папке `relationship-island-ru` (оригинал не тронут);
- вся настройка базы собрана в один файл `supabase/setup-all.sql`;
- есть скрипт переноса острова `scripts/migrate-island.mjs`;
- есть помощник для ключей `scripts/gen-supabase-keys.mjs`.

**Что нужно от тебя (по этой инструкции):** завести сервер, поставить на него Supabase,
и прислать мне два значения — **адрес сервера** и **ANON_KEY**. Остальное доделаю я.

---

## Ориентир по деньгам

- Сервер (VPS) на Timeweb: **≈ 700–1200 ₽/мес** (нужно 4 ГБ оперативной памяти).
- Домен (желательно, для работы на телефоне): **≈ 200–400 ₽/год**.
- Supabase бесплатный (это открытая программа, платишь только за сервер).

---

## Часть 1. Создать сервер на Timeweb Cloud

1. Зайди на **timeweb.cloud**, зарегистрируйся, пополни баланс.
2. Слева выбери **«Облачные серверы»** → **«Создать сервер»**.
3. Настройки сервера:
   - **ОС:** Ubuntu 22.04 (или 24.04).
   - **Конфигурация:** минимум **2 ядра CPU и 4 ГБ RAM** (меньше 4 ГБ Supabase не
     потянет). Диск — 40–50 ГБ достаточно.
   - **Регион:** Россия (Москва/СПб).
   - Если на шаге создания предлагают **готовый образ с Docker** (раздел
     «Маркетплейс» / «Образы приложений») — выбери его, это сэкономит шаг установки
     Docker ниже. Если такого нет — ничего страшного, поставим Docker вручную.
4. Задай/сохрани **пароль root** (или SSH-ключ). Создай сервер.
5. После создания у сервера появится **публичный IP-адрес** (вида `95.163.x.x`) —
   он понадобится дальше.

### Как зайти на сервер

- **С телефона/компьютера** через встроенную веб-консоль Timeweb (кнопка «Консоль»
  у сервера) — проще всего, ничего ставить не надо.
- Или через программу SSH (на Windows — встроенный `ssh` в PowerShell):
  ```
  ssh root@ВАШ-IP
  ```
  и ввести пароль.

## Часть 2. Поставить Docker (если не был в образе)

Вставь команды по одной в консоль сервера:

```bash
apt update && apt install -y docker.io docker-compose-plugin git
systemctl enable --now docker
docker --version
```
Если последняя строка показала версию — Docker готов.

---

## Часть 3. Установить Supabase

1. Скачать официальный Supabase и перейти в папку установки:
   ```bash
   git clone --depth 1 https://github.com/supabase/supabase
   cd supabase/docker
   cp .env.example .env
   ```

2. **Сгенерировать ключи и пароли.** На своём компьютере (в папке
   `relationship-island-ru`) выполни:
   ```
   node scripts/gen-supabase-keys.mjs
   ```
   Скрипт покажет три значения: **JWT_SECRET**, **ANON_KEY**, **SERVICE_ROLE_KEY**.
   Сохрани их (например, в заметку). Придумай ещё два пароля: для базы
   (**POSTGRES_PASSWORD**) и для входа в панель (**DASHBOARD_PASSWORD**).

3. **Открыть файл `.env` на сервере и вписать значения:**
   ```bash
   nano .env
   ```
   Найди и замени (стрелками ищи строки, значения — после `=`, без пробелов):
   - `POSTGRES_PASSWORD=` → твой пароль базы
   - `JWT_SECRET=` → JWT_SECRET из скрипта
   - `ANON_KEY=` → ANON_KEY из скрипта
   - `SERVICE_ROLE_KEY=` → SERVICE_ROLE_KEY из скрипта
   - `DASHBOARD_USERNAME=` → любое имя (напр. `admin`)
   - `DASHBOARD_PASSWORD=` → твой пароль панели
   - `SITE_URL=` → пока поставь `http://ВАШ-IP:8000`
   - `API_EXTERNAL_URL=` → `http://ВАШ-IP:8000`
   - `SUPABASE_PUBLIC_URL=` → `http://ВАШ-IP:8000`

   **Важно для входа по логину/паролю** (в приложении нет почты) — найди и поставь:
   - `ENABLE_EMAIL_SIGNUP=true`
   - `ENABLE_EMAIL_AUTOCONFIRM=true`  ← без этого регистрация будет «ждать письмо»,
     которое никогда не придёт.

   Сохрани: `Ctrl+O`, `Enter`, затем выйди: `Ctrl+X`.

4. **Запустить Supabase:**
   ```bash
   docker compose up -d
   ```
   Первый запуск качает образы — 3–10 минут. Проверить, что всё поднялось:
   ```bash
   docker compose ps
   ```
   Строки должны быть в состоянии `running`/`healthy`.

5. **Открыть панель Supabase Studio** в браузере:
   ```
   http://ВАШ-IP:8000
   ```
   Логин/пароль — те самые DASHBOARD_USERNAME / DASHBOARD_PASSWORD.
   Если панель открылась — Supabase работает. 🎉

> Если Timeweb блокирует порт — в разделе сервера включи/открой порт **8000** в
> файрволе (или напиши мне, разберёмся).

## Часть 4. Настроить базу приложения

1. В Supabase Studio слева открой **SQL Editor** → **New query**.
2. Открой на компьютере файл `supabase/setup-all.sql`, скопируй **весь** текст,
   вставь в окно запроса и нажми **Run**.
3. Должно выполниться без красных ошибок (жёлтые предупреждения — не страшно).
   Это создаст все таблицы, права доступа и серверные функции.

---

## Часть 5. Создать хранилище для фото

1. В Studio слева **Storage** → **New bucket**.
2. Имя бакета: **`event-photos`** (ровно так), включи галочку **Public bucket**,
   создай.
3. Политика загрузки уже включена скриптом из Части 4 (раздел 5 в `setup-all.sql`).
   Если Studio попросит политику отдельно — скажи мне, дам готовую.

---

## Часть 6. Подключить приложение к серверу

Пришли мне два значения:
- **Адрес сервера** (пока `http://ВАШ-IP:8000`, позже — домен, см. Часть 7);
- **ANON_KEY** (публичный ключ, тот же, что вписывал в `.env` сервера).

Я впишу их в файл `.env` копии приложения, соберу веб-версию и синхронизирую Android.
Если хочешь сделать сам — создай файл `.env` в папке `relationship-island-ru`:
```
VITE_SUPABASE_URL=http://ВАШ-IP:8000
VITE_SUPABASE_ANON_KEY=<ANON_KEY>
```
и запусти `npm run dev` для проверки в браузере.

## Часть 7. Домен и HTTPS (нужно для приложения на телефоне)

Для проверки в браузере хватает и `http://IP:8000`. Но **приложение на телефоне
(Android) требует безопасный адрес `https://`** — иначе оно не сможет обращаться к
серверу. Поэтому для телефона нужен домен с сертификатом. Самый простой путь:

1. Купи домен (можно прямо в Timeweb) или возьми бесплатный поддомен.
2. Направь домен (A-запись) на IP сервера.
3. На сервере поставь **Caddy** — он сам получит бесплатный HTTPS-сертификат:
   ```bash
   apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
   curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
   curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' > /etc/apt/sources.list.d/caddy-stable.list
   apt update && apt install -y caddy
   ```
4. Настрой Caddy (замени `supabase.твой-домен.ру`):
   ```bash
   echo 'supabase.твой-домен.ру {
       reverse_proxy localhost:8000
   }' > /etc/caddy/Caddyfile
   systemctl restart caddy
   ```
5. В файле `.env` **сервера** (Часть 3) поменяй три адреса на `https://`:
   `SITE_URL`, `API_EXTERNAL_URL`, `SUPABASE_PUBLIC_URL` → `https://supabase.твой-домен.ру`,
   затем перезапусти: `docker compose up -d`.
6. Пришли мне итоговый адрес `https://supabase.твой-домен.ру` — я пропишу его в
   приложение и пересоберу Android.

> Не хочешь возиться с доменом сам — напиши, проведу по шагам или подскажем более
> простой вариант (например, поддомен от Timeweb).

## Часть 8. Перенести существующий остров

Когда сервер готов и база настроена (Части 3–5), можно перенести твой остров со всеми
воспоминаниями. Подробности — в комментариях файла `scripts/migrate-island.mjs`.
Коротко:
1. Скопируй `scripts/migrate.env.example` → `scripts/migrate.env`, заполни (старый
   логин/пароль, код острова, адрес и ANON_KEY нового сервера, новый логин/пароль —
   аккаунт на новом сервере нужно сначала зарегистрировать в приложении).
2. Запусти:
   ```
   node scripts/migrate-island.mjs
   ```
3. Готово: остров с тем же кодом появится на новом сервере со всеми воспоминаниями,
   фото, покупками, настройками и желаниями.
