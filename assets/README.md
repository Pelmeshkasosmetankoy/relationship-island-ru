# Иконка приложения

Сохраните вашу картинку-иконку сюда под именем **`icon.png`**:

```
C:\Projects\relationship-island-app\assets\icon.png
```

Требования:
- квадратная, лучше всего **1024×1024** пикселя (можно больше);
- формат PNG.

После этого я запущу генератор — он сам создаст все размеры иконок для Android
(и для установки как PWA), и приложение получит вашу иконку.

(Опционально: можно ещё положить `splash.png` 2732×2732 для экрана загрузки —
но это не обязательно.)
