# 3D-модели плиток

Сюда кладутся 3D-модели в формате **`.glb`** (без сжатия Draco). Как только файл
появится здесь и будет прописан в `src/scene/models.js`, плитки этого типа станут
рисоваться этой моделью вместо встроенной графики. Типы, для которых модели нет,
остаются как есть — можно улучшать остров по одному объекту.

## Как добавить модель

1. Положите файл сюда, например `castle.glb`.
2. Откройте `src/scene/models.js` и добавьте строку:
   ```js
   castle: { url: '/models/castle.glb', scale: 1.2, yOffset: 0.6 },
   ```
3. Пересоберите (`npm run build`) — или просто пришлите файл мне, и я подключу
   и подгоню размер/высоту.

## 16 типов (имена файлов — на ваш выбор, главное прописать в models.js)

home, forest, mountains, lake, city, milestone, starfield, coffee, theater,
waterfall, cinema, castle, viewpoint, sakura, sunflower, snowman

## Где взять модели

- **Meshy.ai / Luma Genie / Tripo** — генерация 3D по картинке. Лучший вариант,
  чтобы попасть в стиль ваших референс-иконок: загружаете картинку тайла →
  получаете `.glb`. Экспортируйте как **glTF Binary (.glb)**.
- **poly.pizza** — большая бесплатная библиотека low-poly моделей (замок,
  телескоп, бинокль, снеговик, сакура, подсолнух и т.д.). Часть под CC0, часть
  требует указания автора.
- **Kenney.nl** — бесплатные CC0-наборы (природа, город, замок, праздники) в
  едином стиле.

Совет: держите единый стиль (одинаковый уровень детализации и палитра), чтобы
остров смотрелся цельно.
