# Звуки атмосферы

Сюда кладутся короткие **зацикленные** аудиофайлы `.mp3` для раздела «Звуки» в
лавке. Пока файла нет — товар покупается и включается, но играет тишину (ошибки
не будет). Как только файл появится здесь — звук заработает.

Имена файлов (строго так):

| Файл | Товар |
|---|---|
| `rain.mp3`      | Шум дождя |
| `birds.mp3`     | Пение птиц |
| `campfire.mp3`  | Потрескивание костра |
| `waterfall.mp3` | Звук водопада |
| `crickets.mp3`  | Ночные сверчки |
| `wind.mp3`      | Ветер |

Советы:
- берите короткие «бесшовно зацикленные» лупы (10–30 сек), чтобы не было слышно
  стыка при повторе;
- бесплатные источники: **freesound.org**, **pixabay.com/sound-effects** (можно
  использовать в личном проекте; проверяйте лицензию);
- держите громкость записей примерно одинаковой.

Файлы кладите прямо в эту папку (`public/sounds/`) — при сборке они попадут в
приложение автоматически.
